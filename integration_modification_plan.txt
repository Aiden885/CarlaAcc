# CARLA-Simulink SPPVT集成修改计划

## 核心修改点

### 1. 修改 two_mode_controller.py

**删除导入**:
```python
from sppvt_longitudinal_control import sppvt_longitudinal_control, set_sppvt_parameters, reset_sppvt_controller
```

**添加导入**:
```python
from realtime_sppvt_state_manager import RealtimeSPPVTStateManager
```

**修改 TwoModeController.__init__()**:
```python
# 添加到 __init__ 方法中：
self.sppvt_manager = RealtimeSPPVTStateManager()
self.control_mode_flag = 2  # 默认speed模式
```

**替换所有SPPVT调用**:
- Line 124: `control_output = sppvt_longitudinal_control(speed_error, 0.05)`
- Line 148: `control_output = sppvt_longitudinal_control(time_error, 0.05)`
- Line 167: `control_output = sppvt_longitudinal_control(speed_error, 0.05)`

**改为**:
```python
control_output = self.sppvt_manager.run_single_step_simulation(
    control_error=error_value,  # speed_error 或 time_error
    ego_speed_ms=ego_speed,
    control_mode_flag=self.control_mode_flag,
    control_enabled=True
)
```

**替换参数设置函数**:
- `set_sppvt_parameters(control_mode='speed')` → `self.control_mode_flag = 2`
- `set_sppvt_parameters(control_mode='distance')` → `self.control_mode_flag = 1`
- `reset_sppvt_controller()` → 删除（状态管理器自动处理）

### 2. 修改 acc_planning_control.py

**删除导入**:
```python
# 删除第6行：
from sppvt_longitudinal_control import sppvt_longitudinal_control
```

### 3. 频率设置

- Simulink调用频率: 20Hz (固定，slx文件设计)
- Two Mode计算频率: 保持现有频率

### 4. 错误处理

Simulink调用失败时输出详细错误原因，不使用fallback机制，让问题充分暴露。

### 5. 参数映射

- `control_mode='speed'` → `control_mode_flag=2`
- `control_mode='distance'` → `control_mode_flag=1` (TIME模式)
